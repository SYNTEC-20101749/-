# SYNTEC 发票管理系统 v1.0.16

发布日期：2026-10-24；Windows 文件/产品版本：1.0.16.0。

## 本次更新

- 未分析发票时也可直接勾选“私车公用”、填写行程并单独生成私车 Excel。
- 确认前选择 Excel 保存文件夹；系统记忆上次成功保存的位置，下次仍会弹窗供确认或另选。取消选择不会生成文件，也不会更改已记忆位置。
- 独立导出只生成私车 Excel，不会伪造发票分析结果或自动插入日期汇总行；已有分析结果时仍使用原输出目录。
- Excel 与汇总文件在后台生成，界面保持响应；重复确认会被阻止，校验或导出失败后可修正并重试。
- 关闭保护避免文件生成期间退出造成工作线程异常。

## 安装与使用

1. 下载并完整解压 `SYNTEC-InvoiceManager-v1.0.16.zip`，保留同目录的 `_internal` 文件夹及私车模板。
2. 启动 `SYNTEC-InvoiceManager.exe`，无需单独安装 Python。
3. 需要单独登记私车时，展开“填写补贴/出租车”，勾选“私车公用”并填写有效行程；点击“确认补贴/出租车”，选择 Excel 保存文件夹后等待生成完成。
4. 下次独立导出会默认定位到上次成功保存的位置，但仍可重新选择。取消目录选择不会生成文件。
5. 已完成发票分析时，确认费用仍按原流程更新汇总文件，并将私车 Excel 保存到该分析结果的输出目录。
6. 私车 Excel 打印需要本机安装 Microsoft Excel。不要只复制可执行文件；保留完整发布目录。邮箱账号和授权码保存在本机 Windows 用户设置中，不随发布包携带。

## 构建与验证

- 使用 Python 3.8 发布环境，在 `C:/SYNTECBuild` 纯英文目录构建；采用 onedir、windowed、noupx。
- 打包内置私车 Excel 模板，并将可编辑模板副本放在程序目录；检查 Python DLL、Qt Windows 插件、DPAPI 模块及 OCR 模型。
- 构建脚本执行全套回归测试、验证版本资源为中性语言 `[0, 1200]`，并启动实际交付副本检查主窗口及正常退出。
- 构建验证报告记录本次构建输入的 SHA-256、回归测试结果和 GUI 启动结果；发布提供 SHA-256 校验文件及当前源码快照。
- 本地启动验证不等于目标域控设备策略验证；如目标电脑施加额外安全策略，仍需管理员审批或签名。
