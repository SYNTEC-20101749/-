# SYNTEC 发票管理系统 v1.0.14

发布日期：2026-10-23；Windows 文件/产品版本：1.0.14.0。

## 本次更新

- 出差清单中的网约车金额按已配对行程单的逐笔日期与金额拆分，同一天多笔行程自动累加。
- 示例：22.90 元拆为 2026-08-31 的 12.60 元、2026-09-04 的 10.30 元。
- 与高铁等同日交通费用继续累加，总额不变；不改变发票明细、界面原有汇总、配对、重命名或 Excel 归档。
- 兼容完整日期、月日日期、跨年日期、表头重复及日期/时间分行的常见行程单布局。
- 明细缺失、日期无效或总额不匹配时保留原金额分配，避免漏计及重复计费。

## 安装与使用

1. 下载并完整解压 SYNTEC-InvoiceManager-v1.0.14.zip，保留同目录的依赖文件夹。
2. 启动 SYNTEC-InvoiceManager.exe，无需安装 Python。
3. 重新执行“分析汇总并重命名”，新生成的出差清单即采用按日拆分金额。
4. 不要只复制可执行文件；保留 `_internal` 全部内容。建议解压到有写入权限的普通用户目录。
