# SYNTEC 发票管理系统 v1.0.15

发布日期：2026-10-23；Windows 文件/产品版本：1.0.15.0。

## 本次更新

- 新增私车公用行程登记、里程补贴自动计算、日期汇总和财务模板 Excel 导出。
- 私车补贴及过路费只同步到日期完全匹配的汇总行；同日多笔自动累加，不自动新增日期。对应日期的过路费以私车记录为准，避免与通行费发票重复计算；停车费仅记录在私车 Excel。
- 确认后更新汇总 PDF；一键打印可附加当前已确认的私车 Excel。Excel 按 A5 横向排版，需要本机安装 Microsoft Excel。
- 私车表格字号与日期汇总表统一；确认按钮不再由 Enter/回车触发，启动时默认最大化。
- 关于页面异步检查 GitHub 最新正式版本，提供下载页面入口，不自动下载或安装；使用 Python HTTPS/TLS，不依赖 Qt OpenSSL。
- 修复未匹配日期的私车费用进入汇总的问题。Excel 保留完整明细，但未匹配费用不会进入界面汇总、PDF 或归档总计。

## 安装与使用

1. 下载并完整解压 `SYNTEC-InvoiceManager-v1.0.15.zip`，保留同目录的 `_internal` 文件夹及私车模板。
2. 启动 `SYNTEC-InvoiceManager.exe`，无需单独安装 Python。
3. 使用私车公用功能时勾选相应选项，填写并确认有效行程；私车费用只影响汇总中日期完全相同的项目。
4. 私车 Excel 打印需要本机安装 Microsoft Excel。打印只读打开工作簿，不会关闭用户已有的 Excel 窗口。
5. 不要只复制可执行文件；保留完整发布目录。邮箱账号和授权码保存在本机 Windows 用户设置中，不随发布包携带。

## 构建与验证

- 使用 Python 3.8 发布环境，在 `C:/SYNTECBuild` 纯英文目录构建；采用 onedir、windowed、noupx。
- 打包内置私车 Excel 模板，并将可编辑模板副本放在程序目录；检查 Python DLL、Qt Windows 插件、DPAPI 模块及 OCR 模型。
- 构建脚本执行全套回归测试、验证版本资源为中性语言 `[0, 1200]`，并启动实际交付副本检查主窗口及正常退出。
- 发布包附带构建验证报告，并提供 SHA-256 校验文件及当前运行源码快照。
- 本地启动验证不等于目标域控设备策略验证；如目标电脑施加额外安全策略，仍需管理员审批或签名。
